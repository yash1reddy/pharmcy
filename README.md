# 💊 PharmEasy Regional Pulse: Regional Performance Intelligence Pipeline

An automated, SQL-verified, human-in-the-loop operational monitoring and performance engine designed for the regional leadership team across the Telugu-speaking territories (Telangana, Andhra Pradesh) and the Bengaluru operational hub.

---

## 🚀 1. Setup & Execution Instructions

Run these **three sequential terminal commands** to regenerate the deterministic data streams, execute the cleaning validation pipeline, compute multi-period multi-layered relational performance deltas, and launch the interactive analytics deck:

### Command 1: Install Locked Production Dependencies
```bash
pip install -r requirements.txt
```

### Command 2: Execute the Complete Data Pipeline Lifecycle
This sequence generates the deterministic dataset, runs the data-cleaning engine, creates the SQLite relational database, runs join verifications, applies significance alerts, and runs the human review gate test harness to write the audit trail.
```bash
python3 generate_dataset.py && python3 clean_data.py && python3 build_db.py && python3 metrics_engine.py && python3 review_gate.py
```

### Command 3: Launch the Local Analytics Interactive Cockpit Dashboard
```bash
streamlit run app.py
```

### 1. Headline Regional Operational Finding
The pipeline flagged a major short-term performance anomaly in the **Guntur territory** during the April–May 2026 transitional window, where gross revenue experienced a rapid **+122.19% Month-over-Month surge** (increasing from INR 8,605.95 to INR 19,121.50) before dropping sharply in June.

- **Live Data Exploration**: [Streamlit Dashboard Cockpit (`app.py`)](./app.py) – Provides interactive slice-and-dice data exploration tools across three levels of analytical hierarchy (Overview, Category, Detail).

- **Strategic Recommendation Directive**: [One-Page Management Memo (`memo.md`)](./memo.md) – Delivers clear tactical directions based on the Guntur anomaly, with inline risk-tier tags mapping data reliability.
- **Defensive Presentation Storyline**: [Stakeholder Presentation Script (`presentation_storyline.md`)](./presentation_storyline.md) – Reframes findings for different corporate audiences and provides clear answers for expected stakeholder pushback.

### 4. High-Priority Unverified Assumption Flag
